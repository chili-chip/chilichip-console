# Chilichip Console

Next hardware generation for the Chilichip Console (successor line to VGC Zero).

## Planned PCB

- Mostly **SMD** design
- **MCU integrated** on the board (not a separate module)
- Open hardware — KiCad sources to land here as the revision takes shape
